# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

**In short:** be respectful, assume good faith, critique code rather than people, and
welcome learners of every level, which is what this platform exists for.

Unacceptable behaviour includes harassment, discriminatory language, personal attacks,
publishing others' private information, and sustained disruption of discussions.

Reports can be sent to **satvikpraveen707@gmail.com**. All reports are reviewed promptly
and kept confidential. Maintainers who violate this code may be removed from the project.
